# Packages the figure scripts, the fits and the shared helpers under lib/
# import. Install these before a first run.
#
# Maintained by hand. One package per line, then a comment naming where it
# comes from (CRAN, Bioconductor or GitHub) and the one-line R call that
# installs it on its own, for anyone installing packages one at a time rather
# than through setup/install_packages.R. Everything after # is ignored by the
# scripts that read this file. Change it when a script starts or stops loading
# a package.
#
# Bioconductor packages need BiocManager (install.packages("BiocManager")) at
# the release that pairs with your R: 3.20 on R 4.4, 3.22 on R 4.5. GitHub
# packages need remotes (install.packages("remotes")).
#
# Versions are not recorded here. config/required_packages.tsv pins the five
# whose version changes a panel, and outputs/panels/export_manifest.tsv records
# the data-package versions each PDF was drawn from.
#
# Not listed:
#
#   base, grDevices, grid, stats, utils, methods, ...
#       base-priority, versioned with R itself.
#
#   MotrpacHumanPreSuspensionData, MotrpacHumanPreSuspensionAnalysis
#       the two data packages, installed from source; pinned in
#       config/required_packages.tsv.
#
#   MotrpacHumanPreSuspension
#       a third package the legacy figure scripts called plot_single_feature()
#       from. No script here names it.
#
# Two entries are not on CRAN or Bioconductor and install from GitHub:
# MotrpacBicQC (MoTrPAC/MotrpacBicQC) and PLIER (wgmao/PLIER).
#
# Four are Bioconductor annotation packages rather than software: GO.db and
# AnnotationDbi, which figure_3/ST3.R attaches for ST3g and ST3h, and
# org.Hs.eg.db and TxDb.Hsapiens.UCSC.hg19.knownGene, which annotatr reads
# when figure_6/FIG6_ED8_helpers.R builds the hg19_basicgenes annotation.
# TMSig is on Bioconductor from release 3.20.
#
# setup/install_packages.R installs this list; setup/preflight.sh checks it.
