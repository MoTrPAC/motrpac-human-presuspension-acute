For each folder, the code used to generate the figures is described by the script.R file (e.g. muscle_Figure6_S6_script.R for figure 6.)

The accompanying files in each of the folders are analysis intermediates, external data, pdfs of the outcomes, or adobe illustrator files that describe visual changes that had to be made for the manuscript.

To replicate or perform subanalysis according to the analysis done for the motrpac manuscript, refer to the script file mentioned above. 

Like with the other motrpac manuscripts, some analysis will require access to individual level data that is only obtainable via request to the consortium due to data privacy requirements.
